1. Introduction

FT PVT. LIMITED ("we," "our," or "us") provides APK Shield, an Android application designed to help users inspect APK files and installed applications and access information related to Android application packages.

This Privacy Policy explains the information APK Shield may access, how the application uses device permissions, and how integrated third-party services process information.

We are committed to providing transparent information about the app's privacy-related functionality.

2. APK Files and Installed Application Information

APK Shield includes functionality for examining Android application packages and APK files.

To provide these functions, the application may access:

  • APK files selected or made accessible by the user.
  • Information about applications installed on the device.
  • Application package details and technical metadata.
  • Information required to inspect APK files and display results.

This access supports APK inspection and installed-application analysis.

The presence of these features does not, by itself, establish that APK files or installed-application inventories are uploaded to an external server.

3. Storage and File Access

APK Shield includes Android storage-related permissions to support access to APK files.

Depending on the Android version and permissions granted, the application may access files available through Android's storage system.

The application declares the following storage permissions:

READ_EXTERNAL_STORAGE

Allows access to supported shared-storage content on compatible older Android versions.

MANAGE_EXTERNAL_STORAGE

Allows broader shared-storage access when the user grants the relevant permission through Android settings.

These permissions support the application's APK-file inspection functionality.

Storage access is controlled by Android and the applicable permission settings.

4. Installed Application Visibility

APK Shield declares the Android QUERY_ALL_PACKAGES permission.

This permission supports the application's ability to identify and inspect installed applications.

Information accessible through this permission may include application names, package metadata, version information, and other details exposed through Android's package-management APIs.

The application uses package visibility capabilities to support its app-inspection functionality.

5. APK Installation Functionality

APK Shield declares the REQUEST_INSTALL_PACKAGES permission.

This permission enables the application to request installation of Android application packages through supported Android installation mechanisms.

Android controls whether installation from the application is permitted.

6. Device, Network and Technical Information

APK Shield integrates services that may process technical information necessary for advertising, configuration, and related functionality.

Depending on the integrated service, this information may include:

  • Device model and operating system information.
  • Application version and technical configuration.
  • Network information and IP address.
  • Application or installation identifiers.
  • Advertising identifiers, where available and permitted.
  • App interaction and diagnostic information processed by the advertising SDK.

The specific information processed depends on the SDK, its configuration, Android settings, and applicable user choices.

7. Advertising — Google AdMob

APK Shield includes the Google Mobile Ads SDK (Google AdMob).

Google Mobile Ads may process certain information for advertising delivery, advertising measurement, analytics related to advertisements, and fraud prevention.

According to Google's documentation, the SDK may process:

  • IP address.
  • Advertising ID or other supported identifiers.
  • App interactions associated with advertisements.
  • Device and application information.
  • SDK performance and diagnostic information.

Advertising identifier availability and the use of personalized advertising depend on device settings, SDK configuration, and applicable privacy requirements.

8. Firebase Remote Config

APK Shield includes Firebase Remote Config integration.

Firebase Remote Config enables application configuration values to be retrieved from Google's Firebase service.

According to Google's Firebase documentation, Remote Config may process technical information such as:

  • Country code.
  • Language code.
  • Time zone.
  • Android operating system and platform version.
  • Application identification and version-related information.
  • Firebase Installation ID through Firebase Installations.

This information supports the delivery and management of remote application configuration.

Provider: Google LLC (Firebase)

Firebase Privacy Information: https://firebase.google.com/support/privacy

Firebase Remote Config Documentation: https://firebase.google.com/docs/remote-config

Firebase Data Disclosure: https://firebase.google.com/docs/android/play-data-disclosure

9. Firebase Installations

APK Shield contains the Firebase Installations SDK.

Firebase Installations generates a Firebase Installation ID, which identifies an individual installation of an application rather than directly identifying a person.

Google may process the installation identifier and associated technical metadata to support integrated Firebase services, including Remote Config.

Provider: Google LLC (Firebase)

Privacy Information: https://firebase.google.com/support/privacy

Firebase Installations Documentation: https://firebase.google.com/docs/projects/manage-installations

10. Google Play Billing

APK Shield includes Google Play Billing integration for in-app purchase functionality.

Where a purchase is initiated, Google Play processes the transaction through its billing infrastructure.

The application may access purchase-related information required to verify or manage purchased products, including:

  • Purchased product identifiers.
  • Purchase status.
  • Purchase tokens and associated technical billing information.

Payment processing is governed by Google Play's applicable policies.

This SDK provides consent-management functionality for supported Google advertising integrations.

Where a consent flow is configured and displayed, users may be asked to make applicable advertising privacy choices.

The availability of consent controls depends on the application's implementation and the relevant privacy requirements.

12. Notifications

APK Shield declares the Android POST_NOTIFICATIONS permission.

On supported Android versions, notification permission is controlled through the device's permission system.

Users can manage notification permission through Android settings.

13. Local Application Data

APK Shield includes Android libraries supporting local application storage and background task management.

These components may support storing application settings, processing-related records, or other operational information on the device.

The existence of local storage components does not mean the stored information is automatically sent to an external service.

15. Managing App Permissions

Users can manage supported APK Shield permissions through Android settings.

Depending on their Android version, users may be able to:

  • Allow or deny notification access.
  • Manage storage and all-files access.
  • Control permission to install applications from APK Shield.
  • Change advertising privacy preferences through Android settings.

Disabling a permission required for a particular feature may affect that feature's availability.
