1. Introduction

FT PVT. LIMITED ("we," "us," or "our") provides APK Shield, an Android application designed to help users inspect installed applications, analyze Android application installation packages, and review security-related application information.

This Privacy Policy explains how APK Shield accesses and processes information, how its features use Android permissions, and how integrated third-party services handle information.

We aim to provide clear information about the privacy practices associated with APK Shield.

2. How APK Shield Accesses and Analyzes Applications

APK Shield provides application inspection and analysis features that allow users to review technical and security-related information about Android applications.

To perform these functions, APK Shield accesses and processes relevant information, including:

  • Installed application names and package details.
  • Application version information.
  • Technical information associated with Android applications.
  • Android application installation files accessible through device storage.
  • Application permissions and package metadata.
  • Security-related information identified during application analysis.
  • Analysis results generated by APK Shield.

This information supports APK Shield's application inspection and security analysis features.

Access to installed applications and stored files depends on Android permissions, operating-system restrictions, and device settings.

3. Storage and File Access

APK Shield uses Android storage access permissions to support application package inspection and file analysis.

The application includes the following permissions:

READ_EXTERNAL_STORAGE

Allows APK Shield to access supported shared-storage content on compatible older Android versions.

MANAGE_EXTERNAL_STORAGE

Allows APK Shield to access a broader range of files in shared storage when the user grants the required permission through Android settings.

These permissions support the application's ability to locate, access, and analyze Android application installation files.

Storage access is controlled through Android's permission system. Users can review or change applicable permissions in their device settings.

4. Installed Application Information

APK Shield uses Android's package-management functionality to inspect applications installed on the device.

The application includes the QUERY_ALL_PACKAGES permission to support visibility of installed applications.

The information accessible through this functionality includes application names, package identifiers, application versions, and other technical information made available by Android.

APK Shield processes this information to provide its installed-application inspection and analysis features.

5. Application Installation Functionality

APK Shield includes functionality related to Android application installation packages.

The application declares the REQUEST_INSTALL_PACKAGES permission, which enables APK Shield to request application installation through Android's supported installation mechanisms.

Android manages the relevant installation permissions and user approval requirements.

6. Device Information and Technical Data

APK Shield integrates third-party Google services that process technical information to support advertising, application configuration, and purchase functionality.

Depending on the service, this information includes or may include:

  • Device model and operating-system information.
  • Application version and configuration details.
  • Network information and IP address.
  • Application installation identifiers.
  • Advertising identifiers, where available and permitted.
  • Advertisement interactions.
  • SDK diagnostic and performance information.

The information processed by each service is described in the relevant sections below.

7. Advertising — Google AdMob

APK Shield integrates Google AdMob, an advertising service provided by Google LLC.

The Google Mobile Ads SDK processes information to support advertising delivery, advertising measurement, reporting, and fraud prevention.

According to Google's official documentation, information processed by the SDK includes:

  • IP address.
  • Device and application information.
  • Advertising identifiers, where available.
  • User interactions related to advertising and application activity.
  • Diagnostic and performance information.

Google handles advertising-related information according to its privacy policies, SDK configuration, and applicable privacy requirements.

Users can manage supported advertising privacy settings through their Android device.

8. Firebase Remote Config

APK Shield integrates Firebase Remote Config, a service provided by Google LLC.

Firebase Remote Config supports the retrieval and management of application configuration values.

When Firebase Remote Config communicates with Firebase services, technical information associated with configuration requests may be processed.

According to Firebase documentation, this can include:

  • Application identification and version information.
  • Operating-system and platform information.
  • Language, country, and time-zone information.
  • Firebase Installation ID.

This information supports the operation of Firebase Remote Config.

12. Notifications

APK Shield includes Android notification permission support.

On compatible Android versions, notification access is controlled through Android's notification permission system.

Users can allow, deny, or change the application's notification permission through their device settings.

13. Local Application Data

APK Shield includes Android components that support local application data storage and background processing.

Local application data handling supports the operation of APK Shield's features, including application inspection and related processing.

Information processed by integrated Google services is subject to the relevant third-party service disclosures provided in this Privacy Policy.

14. Third-Party Data Processing

APK Shield integrates the following privacy-relevant third-party services:

  • Google AdMob: Advertising delivery, measurement, and related processing.
  • Firebase Remote Config: Application configuration functionality.
  • Firebase Installations: Firebase installation identification and service support.
  • Google Play Billing: In-app purchase processing.
  • Google User Messaging Platform: Advertising consent-management functionality.

These services are provided by Google LLC and process information according to their applicable privacy policies and service configurations.

Official privacy policies and documentation links are provided in the relevant sections above.

15. Managing Permissions and Privacy Preferences

Users can manage permissions and supported privacy settings through their Android device.

Depending on the Android version and applicable features, these controls include:

  • Storage and file access permissions.
  • Notification permissions.
  • Application installation permissions.
  • Android advertising privacy settings.

Restricting a permission required by a particular APK Shield feature may affect that feature's availability.

For questions about information processed in connection with APK Shield, users may contact FT PVT. LIMITED using the contact information provided below.
