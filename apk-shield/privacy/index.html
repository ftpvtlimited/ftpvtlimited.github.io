1. Introduction

FT PVT. LIMITED ("we", "us", or "our") provides APK Shield, an Android application designed to inspect APK files, examine installed applications, and display information relating to Android application packages.

This Privacy Policy explains the information that APK Shield can access, the permissions associated with its functionality, and the information that integrated third-party services may process.

2. APK Inspection and Application Information

APK Shield includes functionality for inspecting Android application packages and applications installed on the device.

For these functions, the application can access and process:

  • APK files accessible to the application.
  • Installed application names and package information.
  • Application version details.
  • Technical metadata relating to APK files.
  • Information required for APK inspection and analysis.
  • APK analysis results and security-related findings.

This information supports the application's APK inspection and installed-application analysis features.

3. Storage and File Access

APK Shield declares Android storage permissions to support its APK file inspection features.

READ_EXTERNAL_STORAGE

On supported older Android versions, this permission allows the application to read accessible shared-storage content.

MANAGE_EXTERNAL_STORAGE

This permission allows broader shared-storage access when approved by the user through Android's permission settings.

Storage access supports APK file inspection and related file-processing functionality. The availability and scope of storage permissions depend on the Android version and applicable device settings.

4. Installed Application Visibility

APK Shield declares the Android QUERY_ALL_PACKAGES permission.

This permission supports inspection of installed Android applications and access to relevant package information.

Accessible information may include application names, package identifiers, version details, and other metadata exposed by Android's package-management system.

5. APK Installation Permission

APK Shield declares the Android REQUEST_INSTALL_PACKAGES permission.

This permission allows the application to request APK installation through Android's supported installation mechanisms.

Android controls whether installation requests from the application are permitted.

6. Device and Technical Information

APK Shield includes Google services that may process technical information when their functionality is used.

Depending on the service and its configuration, this information may include:

  • Device and operating-system information.
  • Application version and configuration details.
  • IP address and network-related information.
  • Application or installation identifiers.
  • Advertising identifiers, when available.
  • Advertising interactions and SDK diagnostics.

The information processed depends on the integrated service, its configuration, Android settings, and applicable privacy choices.

7. Google AdMob Advertising

APK Shield integrates the Google Mobile Ads SDK, provided by Google LLC.

The SDK supports advertising functionality. According to Google's SDK disclosures, Google Mobile Ads processes information for advertising, measurement, analytics, and fraud prevention.

This information can include:

  • IP address.
  • Advertising and application identifiers.
  • Interactions with advertisements and the application.
  • Device and application information.
  • SDK performance and diagnostic information.

The availability of advertising identifiers and advertising privacy options depends on Android settings, SDK configuration, and applicable privacy requirements.

8. Firebase Remote Config

APK Shield includes Firebase Remote Config integration, provided by Google LLC.

Firebase Remote Config supports retrieval of application configuration values.

According to Firebase documentation, configuration requests may involve technical information such as:

  • Application identification and version information.
  • Operating-system and platform information.
  • Language, country, and time-zone information.
  • Firebase Installation ID.

This information supports Firebase configuration-related services.

12. Notifications

APK Shield declares the Android POST_NOTIFICATIONS permission.

On supported Android versions, users control whether the application is permitted to display notifications.

Notification permission can be managed through Android application settings.

13. Local Application Storage

APK Shield includes Android components supporting local data storage and background task management.

These components support application operations and may retain information associated with local settings, processing, or related functions.

Local storage components do not, by themselves, indicate that locally stored information is transmitted to an external server.

14. Third-Party Service Providers

APK Shield contains the following privacy-relevant Google integrations:

  • Google Mobile Ads (AdMob).
  • Firebase Remote Config.
  • Firebase Installations.
  • Google Play Billing.
  • Google User Messaging Platform SDK.

Each provider's handling of information is described in its relevant privacy policy and technical documentation, linked in the preceding sections.

15. Managing Android Permissions

Users can manage applicable permissions through their device's Android settings.

Depending on the Android version, these settings may include:

  • Storage and all-files access.
  • Notification permissions.
  • Permission to install unknown applications.
  • Android advertising privacy settings.

Restricting a permission needed by a particular feature may prevent that feature from functioning as intended.

16. Changes to This Privacy Policy

Any revised version will display its applicable effective date.
